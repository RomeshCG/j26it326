# Bruno API collection (IMFS)

Shared API testing collection for the team.

## Open in Bruno

1. Install [Bruno](https://www.usebruno.com/)
2. **Open Collection** → select this folder:
   ```text
   docs/bruno/IMFS
   ```
3. Select environment **Local** (top right)
4. Start backend (`cd backend` → `npm run dev`)
5. Run **00 Health → Health**

## Share with teammates (Git)

Yes — Bruno collections are normal files. This collection lives **in the repo**, so:

1. Commit / push `docs/bruno/`
2. Teammates `git pull`
3. In Bruno: **Open Collection** → `docs/bruno/IMFS`

You do **not** need Bruno’s separate “Initialize Git” on `Documents\bruno\IMFS` if the collection is already in this project repo.

### If you already created a collection under Documents

Either:

- **Preferred:** use the repo copy at `docs/bruno/IMFS` (already structured), or  
- Copy your Documents collection into `docs/bruno/IMFS` and commit it

Avoid maintaining two different collections.
